## 🏢 Company Overview

**Akhnaton Trading & Distribution Organization** is a forward-thinking, technology-driven trading and distribution company committed to delivering excellence across supply chain, logistics, and commercial operations. Named after the visionary Egyptian Pharaoh who revolutionized his era, Akhnaton embodies transformation, innovation, and bold leadership in modern business.

We serve a wide range of industries by managing the end-to-end flow of goods — from sourcing and procurement to warehousing, distribution, and last-mile delivery — all powered by a fully integrated digital ecosystem.

## 🌐 Network & Infrastructure

- **Enterprise Network Architecture** — High-availability LAN/WAN with redundant links
- **Cloud Integration** — Hybrid cloud environment (on-premise + cloud)
- **Cybersecurity** — Firewall, IDS/IPS, VPN, Zero Trust Architecture
- **Data Center** — Redundant servers with disaster recovery (DR) site
- **Unified Communications** — VoIP, video conferencing, and collaboration tools
- **SD-WAN** — Software-defined networking for branch connectivity
- **24/7 Network Monitoring** — NOC (Network Operations Center) oversight

| Module | Functionality |
|--------|--------------|

| **Oracle SCM** | Supply Chain, Inventory, Purchasing, Order Management |
| **Oracle HCM** | HR, Payroll, Talent Management |
| **Oracle WMS** | Warehouse Management System |
| **Oracle BI / OTBI** | Reporting, Dashboards, Analytics |
| **Oracle Integration Cloud** | API & system integrations |
| **Oracle Database** | Backend data management for all modules |
